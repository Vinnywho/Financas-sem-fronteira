O <b>Finanças sem Fronteira</b> é uma plataforma web de Educação Financeira Comportamental focada em transformar a percepção do valor do dinheiro e promover qualidade de vida, sustentabilidade e liberdade. O projeto é desenvolvido para atender pessoas de qualquer idade ou atividade profissional.

## 🛠️ Tecnologias e Ferramentas

* **Framework**: React.
* **Linguagens**: JavaScript (ES6+), HTML e CSS.
* **Estilização**: CSS Modules para escopo local e organização.
* **Controle de Versão**: Git/GitHub.
* **Deployment**: Vercel.
